# Ricochet v0.1.19-rc.2 Release Candidate Notes

Date: 2026-06-22

Ricochet v0.1.19-rc.2 is a security hardening release candidate that supersedes
v0.1.19-rc.1 on the same v0.1.19 release train.

## Security Fixes

- Hosted registry discovery now pins discovered mutation and fetch URLs to the
  requested registry origin before bearer tokens are used.
- Hosted registry idempotency records are capped and prune oldest records under
  pressure.
- Runtime approval records can be explicitly released and are capped with
  pruning for expired or final records.
- The VS Code extension now blocks Ricochet run/debug surfaces in untrusted
  workspaces and cleans stack visualizer traces from the OS temp directory after
  loading them.
- MVC AI provider error bodies redact configured API keys before returning
  structured `AiError` results.
- Process and PTY child environments now follow the VM environment policy:
  restricted environment capability clears inherited parent environment, and
  explicit child `env` entries must be allowed by the same env allowlist.
- Linux release signing now cleans up generated GNUPGHOME directories after
  production signature verification.
- MVC session cookies in automatic mode no longer allow a request-supplied
  `Host: localhost` header to remove the `Secure` attribute.
