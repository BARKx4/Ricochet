# Ricochet v0.1.13 Beta Release Notes

Date: 2026-06-17

Ricochet v0.1.13 is a beta developer-target release. It is meant for people
building local tools, MVC apps, packages, GUI experiments, and IDE integrations
with Ricochet. It is not a production platform guarantee.

## Highlights

- Static mirrorable registries: `rco registry rebuild`, `rco registry check`,
  `rco search`, `rco add --registry-url`, scoped package identities, local
  aliases, release-asset archives, and required `sha256:` archive verification.
- First-party beta packages: `@ricochet/auth`, `@ricochet/ai`,
  `@ricochet/forms`, and `@ricochet/test_helpers`.
- GUI v2: webview documents can carry stable state and actions, and
  `rco gui` and `rco package --gui` share the same document/event path.
- Debugger integration: `rco debug-adapter` speaks Debug Adapter Protocol over
  stdio, and the VS Code extension can launch Ricochet debug sessions with the
  live stack visualizer.
- Showcase apps: SQLite notes MVC, package-consuming auth/forms sample, AI
  provider probe, GUI task monitor, and debugger demo.
- Benchmarks: `rco bench --smoke`, `rco bench --iterations N`, and the baseline
  report at `docs/benchmarks/2026-06-17-baseline.md`.

## Release Hardening

- Static registry installs verify archive integrity before extraction and verify
  unpacked package tree integrity before writing lock metadata.
- Archive extraction rejects traversal paths, absolute paths, hard links,
  symlinks, and non-file/non-directory entries.
- Registry metadata rejects malformed indexes, invalid integrity strings,
  duplicate version rows, mismatched package names, mismatched package versions,
  and yanked-only version selections.
- Registry check catches archive integrity drift for local mirror builds.
- HTTP registry failures report normal CLI errors instead of panicking inside
  the async CLI runtime.

## Verification Checklist

Before tagging this release, run:

```powershell
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\docs\reference\validate.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\validate-editor-assets.ps1
cargo run -p ricochet_cli --bin rco -- bench --smoke
```

After the GitHub release workflow publishes artifacts, smoke-test the downloaded
Windows ZIP/installer, Linux tarball/Debian package, macOS unsigned tarballs,
and packaged CLI/GUI/TUI app outputs.
