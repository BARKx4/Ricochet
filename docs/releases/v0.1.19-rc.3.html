Ricochet v0.1.19-rc.3 Release Candidate Notes

Production-facing documentation for Ricochet developers.

On this page Highlights Security Fixes Carried Forward Current Boundaries Verification Checklist

Date: 2026-06-25

Ricochet v0.1.19-rc.3 is the native app UI release candidate on the v0.1.19 train. It supersedes v0.1.19-rc.2 without replacing that immutable candidate tag, and carries forward the rc.2 security hardening fixes.

Highlights

  • @ricochet/ui now provides the backend-neutral native app contract for windows, controls, events, commands, tree views, drag/drop metadata, data grids, and rich text.
  • @ricochet/winui and @ricochet/slint are first-party backend packages with scoped native option helpers, keeping app code portable across native renderers.
  • rco app PATH --backend winui can launch the Windows App SDK / WinUI host when the host is built or provided, while JSON export and replay remain the stable non-window smoke boundary.
  • rco app PATH --backend slint now launches the built-in Slint renderer, and --slint-validate-only compiles the generated native renderer document without opening a window.
  • rco package PATH --app --backend winui|slint creates native app executables through the rco-app launcher. Packaged WinUI apps keep JSON export/replay smoke validation; packaged Slint apps also support RICOCHET_SLINT_VALIDATE_ONLY=1.
  • Windows, Linux, and macOS release packages now include and validate rco-app alongside rco, rco-gui, and ricochet, so packaged native app executables have their launcher in the release bundle.
  • The native_showcase_app.rco release desk combines commands, summary state, a tree view with drag/drop metadata, a data grid, rich text, and stateful update handling in one useful app.
  • Audit policy now records Slint's transitive typed-index-collections / bincode compiler dependency warning explicitly, so `cargo audit --deny warnings` remains green while still failing on new advisories.

Security Fixes Carried Forward

  • Hosted registry discovery pins discovered mutation and fetch URLs to the requested registry origin before bearer tokens are used.
  • Hosted registry idempotency records are capped and prune oldest records under pressure.
  • Runtime approval records can be explicitly released and are capped with pruning for expired or final records.
  • The VS Code extension blocks Ricochet run/debug surfaces in untrusted workspaces and cleans stack visualizer traces from the OS temp directory after loading them.
  • MVC AI provider error bodies redact configured API keys before returning structured AiError results.
  • Process and PTY child environments follow the VM environment policy: restricted environment capability clears inherited parent environment, and explicit child env entries must be allowed by the same env allowlist.
  • Linux release signing cleans up generated GNUPGHOME directories after production signature verification.
  • MVC session cookies in automatic mode no longer allow a request-supplied Host: localhost header to remove the Secure attribute.

Current Boundaries

  • WinUI live rendering is Windows-only and depends on the WinUI host being built or supplied with --winui-host / RICOCHET_WINUI_HOST.
  • The Slint renderer is a v1 native projection with real native buttons for click/command dispatch and readable projected content for richer controls. Fuller retained-control parity can iterate behind the same backend contract.
  • Data-grid and rich-text helpers are useful v1 app contracts, not spreadsheet or full word-processor implementations.

Verification Checklist

Before tagging this candidate, run:

$version = "0.1.19-rc.3"
$smoke = Join-Path (Resolve-Path .\target).Path "rc-prep-smoke\$version"
New-Item -ItemType Directory -Path $smoke -Force | Out-Null

cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo audit --deny warnings
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\docs\reference\validate.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\validate-editor-assets.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\acceptance.ps1

cargo build -p ricochet_cli --bins
.\target\debug\rco.exe app packages\ricochet_ui\examples\native_showcase_app.rco --backend winui --export-ui-json (Join-Path $smoke "native-showcase-winui.json")
.\target\debug\rco.exe app packages\ricochet_ui\examples\native_showcase_app.rco --backend slint --slint-validate-only
.\target\debug\rco.exe package packages\ricochet_ui\examples\native_showcase_app.rco --app --backend winui --app-launcher .\target\debug\rco-app.exe --output (Join-Path $smoke "NativeShowcaseWinui.exe")
$env:RICOCHET_APP_EXPORT_UI_JSON = Join-Path $smoke "packaged-winui.json"
& (Join-Path $smoke "NativeShowcaseWinui.exe")
Remove-Item Env:\RICOCHET_APP_EXPORT_UI_JSON -ErrorAction SilentlyContinue
.\target\debug\rco.exe package packages\ricochet_ui\examples\native_showcase_app.rco --app --backend slint --app-launcher .\target\debug\rco-app.exe --output (Join-Path $smoke "NativeShowcaseSlint.exe")
$env:RICOCHET_SLINT_VALIDATE_ONLY = "1"
& (Join-Path $smoke "NativeShowcaseSlint.exe")
Remove-Item Env:\RICOCHET_SLINT_VALIDATE_ONLY -ErrorAction SilentlyContinue

$releaseOut = Join-Path $smoke "release-windows"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\package-release.ps1 -Version $version -Target windows-x64 -OutDir $releaseOut -SigningMode dry-run
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\validate-release-artifacts.ps1 -Target windows-x64 -OutDir $releaseOut -PackageVersion $version
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\validate-store-packaging.ps1 -Target windows-x64 -OutDir $releaseOut -PackageVersion $version

After the GitHub release workflow publishes artifacts, verify that the release is marked as a prerelease, is not marked latest, includes UPDATE-CHANNEL-candidate.json, and includes the Windows, Linux, and macOS packages plus checksum, signing-status, artifact-manifest, notary, and update channel reports.
