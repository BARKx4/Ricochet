Ricochet v0.1.17 Beta Release Notes

Production-facing documentation for Ricochet developers.

On this page Highlights Verification Checklist

Date: 2026-06-19

Ricochet v0.1.17 is an urgent beta patch release that supersedes v0.1.16. It hardens numeric, date, JSON, template, and retained-resource behavior before more machines install the date/time and float support introduced in v0.1.16.

Highlights

  • Date arithmetic no longer constructs overflowing day durations. Extreme date_add_days input now returns the existing DateRangeError result path instead of risking a panic.
  • Integer clamp validates integer bounds with direct i64 comparison before calling Rust's integer clamp, avoiding precision-loss panics when very large distinct integer bounds round to the same float.
  • Float-to-integer conversion rejects integral floats at or above the exact signed 64-bit upper boundary before casting.
  • MVC/session JSON decoding preserves unsigned integers above i64::MAX as exact strings instead of silently converting them to lossy floats.
  • Template rendering leaves special float values (NaN, inf, -inf) as-is instead of appending an integer-looking .0 suffix.
  • Float truthiness is now explicit: zero and NaN are false; positive, negative, and infinite nonzero floats are true.
  • Retained process, PTY, and HTTP stream release smoke tests now poll bounded status/output readiness instead of relying on fixed sleeps.

Verification Checklist

Before tagging this release, run:

cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo audit --deny warnings
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\docs\reference\validate.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\acceptance.ps1

After the GitHub release workflow publishes artifacts, smoke-test the downloaded Windows ZIP/installer, Linux tarball/Debian package, macOS unsigned tarballs, and packaged CLI/GUI/TUI app outputs.
