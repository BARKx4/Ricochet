# Ricochet v0.1.15 Beta Release Notes

Date: 2026-06-18

Ricochet v0.1.15 is a beta developer-target release for local tools, MVC apps,
packages, GUI experiments, and IDE integrations. It is not a production
platform guarantee.

## Highlights

- Static registry lock hardening: ordinary installs now refuse same-version
  package replacement when locked integrity, provenance, signature metadata, or
  source identity no longer match the current static registry metadata.
- Retained runtime cleanup: `process_release`, `http_stream_release`, and
  `pty_release` drop completed retained handles, while per-host caps prevent
  unbounded retained process, HTTP stream, and PTY registries.
- Date and time library: UTC millisecond timestamps, RFC3339 parse/format
  helpers, Chrono-style pattern formatting, date arithmetic, and explicit
  duration unit builders are available as first-party words.
- Float and numeric conversion support: decimal/exponent literals produce
  finite `Float` values, mixed numeric math promotes to floats, JSON and MVC
  scalar bridges preserve fractional values, and checked conversion words cover
  integer ranges, unsigned ranges, float32 rounding, and float64 aliases.
- Maintenance feature map: `docs/feature-map.md` records implemented surfaces,
  evidence files, explicit boundaries, and assumptions to re-check before future
  roadmap work.
- Syntax cleanup: static import strings now reject invalid escapes consistently
  with normal strings, and leading-dash words remain reserved for subtraction
  and negative number literals.
- Package and release polish: first-party packages are included in release
  payloads, package examples use tracked `@ricochet/forms` sources, and release
  workflows enforce Cargo-version alignment.
- Audit policy is explicit: accepted GTK/WebKitGTK beta-stack warnings live in
  `.cargo/audit.toml`, allowing `cargo audit --deny warnings` to fail on new
  advisories.

## Verification Checklist

Before tagging this release, run:

```powershell
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo audit --deny warnings
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\acceptance.ps1
```

After the GitHub release workflow publishes artifacts, smoke-test the downloaded
Windows ZIP/installer, Linux tarball/Debian package, macOS unsigned tarballs,
and packaged CLI/GUI/TUI app outputs.
