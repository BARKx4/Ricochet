Ricochet v0.1.19-rc.1 Release Candidate Notes

Production-facing documentation for Ricochet developers.

On this page Highlights Verification Checklist

Date: 2026-06-22

Ricochet v0.1.19-rc.1 is the first public release candidate after the roadmap closure audit. It builds on the v0.1.18 network and host-boundary hardening, then adds the final distribution checks needed to exercise the Windows, Linux, and macOS release surface before a stable v0.1.19 tag.

Highlights

  • The roadmap closure audit now has green local gates, green branch CI, and a green release workflow dry run covering Windows, Linux, and both macOS targets.
  • Release packaging now validates artifact manifests, store-ready package shape, signing-status reports, update-channel metadata, and combined checksum output before GitHub release publication.
  • Semver prerelease tags are published as GitHub prereleases, are not marked latest, use the dry-run signing/notarization path, and write UPDATE-CHANNEL-candidate.json with SHA-256 verification metadata instead of the stable update-channel file.
  • Public documentation now separates implemented roadmap scope from future extensions and keeps local maintenance notes out of the README surface.
  • The v0.1.18 hardening remains included: TCP/WebSocket client and listener words, host allow-list resolution checks, WebSocket origin checks, bounded stream reads, package registry hardening, MVC capability narrowing, AI and database host-boundary checks, process-root enforcement, and editor trust handling.

Verification Checklist

Before tagging this candidate, run:

cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo audit --deny warnings
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\docs\reference\validate.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\validate-editor-assets.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\acceptance.ps1

After the GitHub release workflow publishes artifacts, verify that the release is marked as a prerelease, is not marked latest, includes UPDATE-CHANNEL-candidate.json, and includes the Windows, Linux, and macOS packages plus checksum, signing-status, artifact-manifest, notary, and update channel reports.
