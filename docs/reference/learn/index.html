Manual Chapters

The first Learn Ricochet manual will be organized around the way a new developer naturally builds confidence: small stack programs, named code, app structure, then production-minded tooling.

1. Orientation What Ricochet is for, how postfix programs read, and how the `rco` toolchain fits scripts, MVC apps, packages, and desktop builds.
2. Stack And Values Numbers, strings, booleans, arrays, maps, results, and the core habit of keeping inputs below the word that consumes them.
3. Flow And Functions Blocks, conditionals, loops, named functions, argument metadata, error handling, and readable public word naming.
4. Objects And Records Classes, fields, accessors, methods, model table mappings, and the receiver-before-selector style used across the language.
5. Web Apps Routes, controllers, views, request data, sessions, uploads, hot reload, static assets, and local app development with `rco serve`.
6. Data And Migrations SQLite, PostgreSQL, MySQL, Active Record queries, inserts, updates, schema migrations, rollback, dump, and seed workflows.
7. Host Capabilities Filesystem, HTTP, process, PTY, sockets, environment, secrets, approvals, and the difference between trusted and sandboxed runs.
8. Packages And Registries Dependencies, lockfiles, audits, static and hosted registries, package publishing, static imports, and dynamic runtime imports.
9. Tools And Release Formatting, linting, tests, debugging, editor support, packaging, release artifacts, update channels, and validation before shipping.
