# Appendix D: Syntax Guardrails

## Purpose

This appendix will keep the accepted Ricochet syntax shapes easy to check while reading the manual.

## Planned Coverage

- Receiver-before-selector forms such as `user email.get`.
- Argument order for selectors.
- Container-before-key access and mutation.
- `_` word naming, `-` subtraction, `$name` reads, dynamic `get`, selectors, blocks, and OOP declarations.
- Corrections for tempting forms that do not match Ricochet syntax.
