# Chapter 11: OOP And Dispatch

## What You Will Build

This chapter will build a contact-book model using Ricochet's dynamic OOP vocabulary.

## Concepts

- Class bodies and postfix declarations.
- Fields, accessors, methods, inheritance, and overrides.
- Generated selectors such as `email.get` and `email.set`.

## Words Introduced

Primary coverage: OOP detail words from the live word inventory.

## Guided Example

Planned example: `examples/learn/11-oop/contact-book.rco`.

## Try It

Readers will create an instance, send messages, and override one method.

## Common Mistakes

- Writing receiver-first pseudo-object calls instead of postfix selectors.
- Using class declarations when a map would be simpler.

## What You Know Now

Readers will understand the OOP vocabulary reused by MVC model declarations.
