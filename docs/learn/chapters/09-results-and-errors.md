# Chapter 09: Results And Errors

## What You Will Build

This chapter will build a config-loader flow that treats errors as explicit values.

## Concepts

- `ok` and `fail` values.
- Unwrapping, mapping, chaining, and envelopes.
- API boundaries that return structured results.

## Words Introduced

Primary coverage: result detail words from the live word inventory.

## Guided Example

Planned example: `examples/learn/09-results-and-errors/config-loader.rco`.

## Try It

Readers will handle success and failure without hiding either path.

## Common Mistakes

- Treating `Result` values as conditions.
- Unwrapping before deciding what failure should mean.

## What You Know Now

Readers will be ready to work with host APIs and conversions that can fail.
