# Chapter 10: Control Flow, Functions, And Blocks

## What You Will Build

This chapter will build a small gradebook program.

## Concepts

- `if`, `else`, `while`, `break`, `continue`, and `return`.
- First-class blocks and `call`.
- Function declarations and readable factoring in postfix style.

## Words Introduced

Primary coverage: control words other than async task words, which are taught in Chapter 15.

## Guided Example

Planned example: `examples/learn/10-control-flow/gradebook.rco`.

## Try It

Readers will extract repeated logic into functions and blocks.

## Common Mistakes

- Forgetting that arguments still arrive through postfix stack order.
- Hiding too much behavior in anonymous blocks.

## What You Know Now

Readers will be able to structure Ricochet programs beyond straight-line scripts.
