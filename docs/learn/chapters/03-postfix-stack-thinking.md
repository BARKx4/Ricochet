# Chapter 03: Postfix Stack Thinking

## What You Will Build

This chapter will build a receipt-style calculation that makes stack movement visible.

## Concepts

- Before-and-after stack diagrams.
- Stack manipulation as a tool, not a goal.
- When named bindings are clearer than deeper stack juggling.

## Words Introduced

Primary coverage: `swap`, `dup`, `drop`, `over`, `rot`, `nip`, `tuck`, `pick`, `roll`, `depth`, `clear`.

## Guided Example

Planned example: `examples/learn/03-stack/receipt.rco`.

## Try It

Readers will predict stack states before running each expression.

## Common Mistakes

- Keeping values on the stack longer than needed.
- Using stack motion where a named binding would be easier to read.

## What You Know Now

Readers will be able to read simple postfix expressions from left to right.
