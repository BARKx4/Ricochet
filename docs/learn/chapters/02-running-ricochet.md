# Chapter 02: Running Ricochet

## What You Will Build

This chapter will build confidence with running files, using the REPL, reading help, and recognizing diagnostics.

## Concepts

- `rco run`, `rco repl`, and command help.
- Parse errors, stack errors, and type errors.
- Source-file conventions and prompt style.

## Words Introduced

This chapter reinforces comments, strings, integer literals, and float literals.

## Guided Example

Planned example: `examples/learn/01-hello-world/repl-notes.rco`.

## Try It

Readers will run help commands and compare a successful script with intentional diagnostics.

## Common Mistakes

- Reading a runtime stack error as a parser problem.
- Assuming the REPL and file runner use different language rules.

## What You Know Now

Readers will know the basic feedback loop for trying Ricochet code safely.
