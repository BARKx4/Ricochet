# Chapter 04: Values And Literals

## What You Will Build

This chapter will build a value tour that prints and inspects representative Ricochet values.

## Concepts

- Runtime value families.
- Integer, float, string, boolean, nil, collection, block, task, result, regex, and capability values.
- Truthiness, NaN, infinities, and empty values.

## Words Introduced

Primary coverage: `nil`, `true`, `false`, `nil?`, `empty?`, `type`, `inspect`.

## Guided Example

Planned example: `examples/learn/04-values/value-tour.rco`.

## Try It

Readers will inspect values and compare their displayed type names.

## Common Mistakes

- Assuming every non-boolean condition behaves like another language.
- Treating decimal literals as integers.

## What You Know Now

Readers will know the major value categories before learning mutation or control flow.
