# Chapter 00: Orientation

## What You Will Build

This opening chapter will orient readers to Ricochet, the `rco` toolchain, the reference site, and the examples directory. It does not need a runnable example.

## Concepts

- Ricochet as a language and application toolchain.
- Why the manual teaches postfix stack programming first.
- How tutorials, reference pages, wiki notes, and examples fit together.

## Words Introduced

This chapter introduces the `rco` command and documentation layout rather than language words.

## Guided Example

No guided example is planned for this chapter.

## Try It

Readers will confirm that `rco --help` is available and locate the reference documentation.

## Common Mistakes

- Treating the manual as a complete command reference.
- Skipping the postfix model before reading MVC or package chapters.

## What You Know Now

Readers will know where the manual starts, how the learning path is organized, and where to look for deeper reference material.
