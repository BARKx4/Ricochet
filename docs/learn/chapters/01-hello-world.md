# Chapter 01: Hello World

## What You Will Build

This chapter will build the first Ricochet script: a one-line program that prints a greeting.

## Concepts

- Source files and `rco run`.
- The smallest useful stack diagram.
- Comments and simple string output.

## Words Introduced

Primary coverage: `print`, comments, and stack input/output notation.

## Guided Example

Planned example: `examples/learn/01-hello-world/hello.rco`.

## Try It

Readers will run the script from a terminal and enter the same expression in the REPL.

## Common Mistakes

- Reversing the value and word order.
- Expecting infix or object-call syntax in the first example.

## What You Know Now

Readers will understand that Ricochet words consume values already on the stack.
