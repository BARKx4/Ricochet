# Ricochet Benchmark Baseline

Date: 2026-06-17
Version: 0.1.13 beta candidate
Command: `rco bench --iterations 5`
Host: local Windows developer machine

These numbers are local-run medians, not cross-language shootout claims. Use
them for website copy as beta baseline figures and refresh them before major
performance announcements.

| Benchmark | Workload | Median | Throughput | Notes |
| --- | ---: | ---: | ---: | --- |
| parser | 2000 source lines | 3.891 ms | 513.97k ops/s | `parse_module` over generated arithmetic source |
| compiler | 2000 source lines | 6.161 ms | 324.64k ops/s | `compile_source` over generated arithmetic source |
| vm_arithmetic | 20000 additions | 25.144 ms | 795.41k ops/s | fresh VM running precompiled stack arithmetic |
| dispatch | 2500 function + method pairs | 29.130 ms | 171.64k ops/s | user function and OOP method calls |
| collection_mutation | 20000 array `push!` calls | 40.834 ms | 489.78k ops/s | array mutation through collection helpers |
| json_encode_decode | 1000 object items | 19.130 ms | 52.27k ops/s | JSON encode/decode of a generated nested map |
| template_rendering | 1000 template expressions | 40.832 ms | 24.49k ops/s | HTML template rendering with Ricochet expressions |
| package_verification | 5 package files | 0.484 ms | 10.34k ops/s | deterministic package tree integrity hash |
| sqlite_mvc_request | 100 GET `/users` requests | 47.251 ms | 2.12k ops/s | in-process Axum route through Ricochet MVC + SQLite Active Record |

CI runs `rco bench --smoke` to keep the benchmark harness alive without making
ordinary verification slow.
