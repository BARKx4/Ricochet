Ricochet 2 ADR-001 typed-postfix surface proof

This preserved prototype makes the first proposed-syntax claims executable:

  • every source byte and comment survives the lossless CST round trip;
  • the formatter reaches a fixed point after one pass;
  • typed declarations become semantic AST declarations and explicit stack rows;
  • deliberate errors produce stable diagnostic codes and byte spans;
  • deterministic mutation fuzzing exercises recovery without panics.
cargo run -p ricochet2_surface_prototype --bin ricochet2-surface-proof -- demo
cargo test -p ricochet2_surface_prototype

The inspect, check, and format commands accept a source path. The valid and invalid source corpora live in the adjacent fixtures directory.

Boundary: this is architecture evidence. It is not the production Ricochet 2 frontend, does not accept ADR-001, and does not create Ricochet 1 compatibility obligations. The source remains in the repository even if the proposal is rejected.
